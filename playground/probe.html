如果卡在「下载中」

      

        

          内置翻译模型的下载和 Gemini Nano 是两套东西，它在 Chrome 里仍然需要单独打开，也有专门的
          internals 页面。按下面顺序排查（每步都很快）：
        

        
    
          
  1. 
            确认实验性翻译 API 已启用。新标签页打开
            chrome://flags/#translation-api
            
            ，把「Experimental translation API」设为 Enabled，然后重启 Chrome。
          
    2. 
          
  2. 
            直接看语言包装没装。新标签页打开
            chrome://on-device-translation-internals
            
            ，这个页面会列出所有语言包，可以手动下载，也会显示下载失败的原因。
            翻译需要源语言和目标语言两个包都装（en 和 zh）。
            
    如果这个页面打不开或没有内容，说明这台机器/这个版本根本不支持内置翻译。
          
    3. 
          
  3. 
            顺带看一眼组件状态。
            chrome://components
            
            ，找与 Translation / Optimization Guide 相关的条目，点「检查是否有更新」。
            如果版本是 0.0.0.0 且更新不动，就是组件根本没下发下来。
          
    4. 
          
  4. 
            确认是安全上下文。本页应当显示 Secure Context: true。
            如果是从 file:// 打开的，请改用
            http://localhost:5174/probe.html。
          
    5. 
        

        

          上面都做完还是不行，就把日志贴回来 —— 我们能确定是「API 不可用」「语言包下不来」还是
          「本机硬件不支持」，然后决定翻译改走云 API 还是降级读原文。
